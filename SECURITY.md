# Security policy

## Reporting a vulnerability

Use GitHub to [report a vulnerability privately](https://github.com/smallprimitives/taskfence/security/advisories/new). Keep vulnerability details in the private report while maintainers investigate and coordinate disclosure.

Include the affected module version or commit, your Go version, the expected and observed behavior, and a minimal example with synthetic data. Describe the impact you observed and any conditions needed to reproduce it.

## Supported versions

Task Fence is in initial development. Security fixes currently target the development branch. Once releases are available, fixes will target the latest published release series. Maintainers will publish a GitHub security advisory when appropriate.
